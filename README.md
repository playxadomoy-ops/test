# Air Alert Analyzer

Центр моніторингу повітряних тривог України: реальна геокарта областей,
rule-based аналіз Telegram-повідомлень (без AI), рівень небезпеки,
статистика, журнал подій — на Python + **Flet 0.28.3**, Android-first.

## Вимоги

- Python 3.11+
- Flet **саме** 0.28.3 (`pip install flet==0.28.3`)
- Telethon (Telegram), httpx (alerts.in.ua)

```bash
pip install -r requirements.txt --break-system-packages   # або у venv без цього прапорця
```

## Запуск на комп'ютері (для розробки)

```bash
python main.py
```

Десктопне вікно відкривається лише для зручності розробки; сам інтерфейс
спроєктований Android-first (єдина колонка, без десктопного розкладу
side-by-side) і однаково виглядає на телефоні.

## Збірка APK

### Автоматично через GitHub Actions (рекомендовано)

У репозиторії є готовий workflow `.github/workflows/build-apk.yml`:

1. Запуште код у GitHub-репозиторій.
2. Відкрийте вкладку **Actions** → **Build Android APK** → **Run workflow**
   (або просто запуште у `main`/`master` — спрацює автоматично).
3. Після завершення збірки завантажте готовий `.apk` з артефакту
   `air-alert-analyzer-apk` на сторінці запуску.

Workflow ставить Python, Java (Temurin 17) та Flutter (версія зафіксована
під `flet==0.28.3`), встановлює залежності з `requirements.txt` і виконує
`flet build apk --verbose`.

### Локально

```bash
pip install "flet[all]==0.28.3"
flet build apk
```

Готовий `.apk` з'явиться в `build/apk/`. Для локальної збірки потрібні
Flutter SDK, Java (JDK 17) та Android SDK/NDK — простіше скористатись
готовим GitHub Actions workflow вище, який усе це піднімає сам.

## Налаштування Telegram

1. Отримайте **API ID** та **API HASH** на https://my.telegram.org.
2. Введіть їх у вкладці **Налаштування**.
3. Натисніть **«Увійти в Telegram»** — застосунок запитає номер телефону,
   код підтвердження, і (якщо увімкнено) пароль двофакторної автентифікації.
4. Після успішного входу сесія (Session String) зберігається локально —
   повторний вхід при наступному запуску не потрібен.

## Налаштування джерела офіційних тривог (необов'язково)

Карта областей оновлюється з двох джерел одночасно:

1. **Rule-based аналіз Telegram-повідомлень** — працює одразу, токен не потрібен.
2. **Офіційне API alerts.in.ua** — це **не анонімний** ендпоінт: потрібен
   персональний токен, який видається через форму запиту на
   https://alerts.in.ua/api-request. Введіть токен у полі
   «Токен alerts.in.ua» на вкладці Налаштування. Якщо токен не вказано,
   застосунок просто пропускає цей запит (пише про це в журнал) і працює
   лише на основі Telegram-аналізу — це не є помилкою.

## Карта України

Карта — це **реальні географічні межі** 27 областей (спроєктовані та
спрощені під мобільний рендеринг, дані `app/ukraine_geo.py`), намальовані
одним SVG-зображенням (`ft.Image(src_base64=...)`), а не сіткою кнопок:

- **білий** — тривоги немає;
- **червоний** — активна тривога.

Дотик по мапі визначає область через point-in-polygon тест по тих самих
координатах, що використовуються для малювання, тому область натискання
завжди точно збігається з намальованою фігурою. Розмір мапи рахується від
фактичної ширини сторінки (`page.on_resized` → `UkraineMap.resize()`) —
без фіксованих пікселів, коректно на будь-якому екрані та після повороту.

## Архітектура

```
air_alert_analyzer/
├── main.py                       # єдина точка входу
├── .github/workflows/
│   └── build-apk.yml              # CI-збірка APK
├── assets/
│   └── icon.png                    # іконка застосунку (512×512)
├── app/
│   ├── config.py                    # константи, ключі сховища
│   ├── ukraine_geo.py                # реальні межі 27 областей (SVG + полігони)
│   ├── models/                        # dataclass-моделі (без бізнес-логіки)
│   ├── storage/                        # обгортка над page.client_storage
│   ├── services/                        # LoggerService, RiskAnalyzer, AlertService
│   ├── telegram/                         # TelegramService (Telethon)
│   └── ui/
│       ├── theme/                         # кольори/тема
│       ├── components/                     # ThreatCard, UkraineMap, StatsPanel, ...
│       └── views/                           # Огляд, Канали, Лог, Налаштування
```

Усі сервіси створюються один раз у `main.py` і передаються через
конструктор (Dependency Injection) — жодних глобальних змінних. UI не
містить бізнес-логіки: компоненти й views отримують готові дані та
callback-и.

## Головний екран ("Огляд")

Зверху над вкладками — постійна панель (дзвіночок «сповіщення» + шестерня
налаштувань). Сама вкладка «Огляд» зверху вниз:

1. картка **«тривога»** — час останнього оновлення, кольоровий квадрат
   (з підсвіткою під колір рівня загрози) і короткий статус («Чисто» тощо);
2. рядок **«тг канали»** — дотик переносить на вкладку «Канали»;
3. **карта України** з реальними межами областей;
4. (нижче, при прокрутці) статистика та стрічка останніх повідомлень —
   збережено функціонал, а не прибрано заради вигляду.

Вкладки «Канали», «Лог» і «Налаштування» повністю функціональні: додавання/
вимкнення/видалення каналів, живий журнал подій з очищенням, форма
налаштувань зі збереженням і скиданням, вхід у Telegram через діалоги.

## Захист від білого екрана

`main()` спершу синхронно будує **весь** інтерфейс з безпечними значеннями
за замовчуванням і додає його на сторінку. Лише після цього запускається
фонове завантаження збережених даних і сервісів
(`page.run_task(_initialize)`). Будь-яка помилка на цьому етапі
перехоплюється, пишеться в журнал і показується коротке снекбар-повідомлення
— застосунок ніколи не залишається з порожнім екраном.

## Що перевірено перед здачею

- Усі використані властивості/методи Flet звірені з реально встановленим
  пакетом `flet==0.28.3` (інспекцією коду в пісочниці), а не з пам'яті —
  включно з `GestureDetector`, `Image` (SVG через `src_base64`),
  `page.on_resized`, `page.open`/`page.close`, `client_storage.*_async`.
- Кожен файл пройшов `python -m py_compile` (синтаксис, відступи) —
  жодного `IndentationError`.
- Повний імпорт усіх модулів проєкту виконано без `ImportError` і без
  циклічних імпортів.
- `main()` прогнано повністю (build → mount → `_initialize`) проти
  фейкового Flet `Connection`/`Page` без винятків; окремо перевірено
  point-in-polygon визначення області по координатах дотику (усі 27
  областей резолвляться коректно), вміст діалогу картки області, перемикання
  вкладок і збереження налаштувань.
- `pyproject.toml` і GitHub Actions workflow провалідовано парсерами
  TOML/YAML.
- У кодовій базі відсутні застарілі виклики (`page.window_width`,
  `ft.colors.*`, `ft.icons.*` у нижньому регістрі тощо) — перевірено
  скануванням усіх файлів.

## Відомі обмеження

- Офіційне API alerts.in.ua вимагає токен — без нього застосунок працює
  лише на Telegram-аналізі (це очікувана поведінка, не помилка).
- Інтерактивний вхід у Telegram реалізований через прості діалоги
  (телефон → код → 2FA-пароль); QR-вхід не реалізовано.
- Сам процес `flet build apk` (компіляція Flutter/Gradle) не виконувався
  в середовищі підготовки цієї відповіді — немає Android SDK/Flutter у
  пісочниці. Перевірено все, що можливо на рівні Python/Flet API та логіки;
  фінальну збірку виконає GitHub Actions workflow або локальне середовище
  з Flutter.
